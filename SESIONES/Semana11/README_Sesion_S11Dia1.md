# Día 1 — Actuator, health y logs estructurados

## Objetivos
Operar una aplicación Spring Boot con señales útiles y seguras.

## Contenido
- Actuator y exposición mínima;
- liveness frente a readiness;
- correlation ID validado;
- logs JSON, niveles y timestamps UTC;
- prohibición de contraseñas, tokens y payloads sensibles.

## Laboratorio
Seguir una inscripción desde HTTP hasta PostgreSQL/outbox mediante correlation ID. Detener PostgreSQL y diferenciar proceso vivo de servicio no preparado.

## Evidencias
Logs consultables, health groups y pruebas del filtro de correlación.
