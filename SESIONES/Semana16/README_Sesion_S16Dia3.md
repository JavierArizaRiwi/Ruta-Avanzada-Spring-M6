# Día 3 — Cierre y defensa técnica

## Objetivos
Demostrar la evolución completa y defender decisiones/costos.

## Demo obligatoria
1. Arranque local documentado.
2. Registro/login y permisos.
3. Inscripción con PostgreSQL/Flyway.
4. Caché observable.
5. Outbox → Kafka → consumidor idempotente.
6. Fallo y recuperación.
7. Métricas/dashboard.
8. Pipeline Java 17/21 verde.

## Documentación final
Diagramas, ADR, OpenAPI, eventos, variables, runbooks, estrategia de seguridad y limitaciones del laboratorio.

## Evaluación
Funcionalidad 25%, arquitectura 20%, pruebas 20%, operación/seguridad 20%, defensa 15%.
